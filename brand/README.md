# Shydel brand assets

The mark is a four-slice circle: three slices in ink, one in Shydel blue lifted out of the circle — the whole portfolio, with one position in focus. The wordmark is Schibsted Grotesk ExtraBold with -0.03em tracking, the same face the site uses, converted to outlines so the SVGs need no web font.

Colours: ink `#0E0E0E`, blue `#2340D9`, cream `#F3F2EE`.

## Files

Source logo files live in `../assets/logo/` (they are served with the site):

- `shydel-mark.svg`, `shydel-mark-white.svg` — the mark alone (light / dark backgrounds)
- `shydel-logo.svg`, `shydel-logo-white.svg` — horizontal lockup, mark + wordmark
- `shydel-wordmark.svg` — the wordmark alone
- `shydel-logo-1600.png`, `shydel-logo-white-1600.png` — lockup as PNG for email, decks, docs

Exports in this folder:

- `youtube-profile-light-800.png` — channel profile picture (YouTube crops it to a circle; 800×800, recommended)
- `youtube-profile-dark-800.png` — the same on ink, if the channel uses dark art
- `youtube-banner-2560x1440.png` — channel banner; the logo and tagline sit inside YouTube's 1546×423 safe area so they show on every device
- `preview-sheet.png` — the lockup on cream, ink and blue, and the mark at 16–96 px

## Rules of thumb

- Keep clear space around the lockup of at least the mark's height.
- Do not recolour the blue slice; on dark backgrounds use the white versions.
- Below 24 px use the mark alone, not the lockup.
- `linkedin-cover-2256x382.png`, `linkedin-cover-cream-2256x382.png` — LinkedIn company page cover, ink and cream versions (2× of LinkedIn's 1128×191); lockup and tagline sit centre-right so the square page logo, which overlaps the bottom-left on desktop, never covers them
- `linkedin-profile-banner-1584x396.png` — LinkedIn personal profile banner for the founders; content sits in the right half, clear of the profile photo at bottom-left
